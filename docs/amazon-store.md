# AuronixDirect Amazon store page

`/amazon-store` introduces Auronix Commerce LLC's AuronixDirect selling presence and links to the user-provided storefront `https://amazon.com/shops/AuronixDirect`. Header/mobile/footer information links lead to this page; the page and homepage contain prominent orange outbound storefront actions. The page is indexed in site navigation/search and the sitemap.

Content describes how to review listings, verify seller/fulfillment, continue checkout on Amazon, and find order support. It does not invent inventory, reviews, sales counts, Prime eligibility, shipping guarantees or return promises. Current listing details remain on Amazon.

The unmodified US English horizontal squid-ink “Available at Amazon” PNG is extracted from Amazon's published badge package:
https://m.media-amazon.com/images/G/01/AdProductsWebsite/images/AUX/brand-usage/Available_at_Amazon_US_Ex.zip
Guidance/source: https://affiliate-program.amazon.com/help/operating/amazonmarks/
The 1500×242 original is stored at `public/brand/available-at-amazon.png`, displayed at no less than 140 CSS pixels wide, with clear space and a contrasting orange background. It is used as a shopping link, not an Amazon endorsement of Auronix. Amazon trademark attribution appears on the dedicated page.
